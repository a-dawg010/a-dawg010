SIDE OF THE DESK

01  ·  CLI  ·  PYTHON, STDLIB ONLY

assay

what left the machine, and when.

Your coding agents write every session to disk in plaintext, with the working directory attached. Nobody reads those files, so nobody notices they add up to an egress log — a record of what left the machine that the vendors do not provide. assay reconstructs which repository went to which vendor and when, and is equally clear about what it cannot see. A gateway cannot be installed retroactively; these files are already there.

02  ·  macOS  ·  SWIFT 6  ·  NO DEPENDENCIES

shelfmark

not what it’s about. where it is.

A shelfmark is the notation a library puts on an item saying exactly where it lives. Ask where a file is and you get the path — not a summary, not a chat. Two lists, labelled and never blended: BM25 over a lexical index, and a MiniLM embedding index running on device with a cosine floor, so nonsense returns nothing instead of six confident wrong files. Everything stays on the Mac.

how I think about it

THREE RULES

01

Decide, then execute.

The part that chooses which tool to reach for should be separate from the part that reaches. One prompt doing both is a system you cannot debug at 2am.

02

Relationships beat similarity.

A vector index tells you a document mentions the thing. A graph tells you what sits two hops downstream of it. In security work that distance is the answer.

03

If it can’t be traced, it isn’t an answer.

Anything that ends up in front of an assessor, a regulator or an on-call engineer has to carry the path it took to get there. Confidence is not evidence.
