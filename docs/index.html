SIDE OF THE DESK

01  ·  CLI  ·  PYTHON

assay

your agents are hoarders.

Coding agents are messy guests. Scratch checkouts, dependency caches, whole VMs — the session ends and nobody remembers any of it existed. assay finds what Claude Code, Cursor, Codex and Antigravity left behind, attributes each find to the harness that made it, and sorts by what you would actually get back. Nothing dies without you saying so.

02  ·  LOCAL  ·  SEMANTIC INDEX

shelfmark

talk to your storage.

Search on your own machine is still filename matching in a nicer coat. You remember what the document said, not what you called it. shelfmark indexes content instead of names and answers a plain-English question with the file itself — no folder tree to walk, no page of results ranked by how closely a filename matched.

how I think about it

THREE RULES

01

Decide, then execute.

The part that chooses which tool to reach for should be separate from the part that reaches. One prompt doing both is a system you cannot debug at 2am.

02

Relationships beat similarity.

A vector index tells you a document mentions the thing. A graph tells you what sits two hops downstream of it. In security work that distance is the answer.

03

If it can’t be traced, it isn’t an answer.

Anything that ends up in front of an assessor, a regulator or an on-call engineer has to carry the path it took to get there. Confidence is not evidence.
